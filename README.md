# km-ocr
This repo contains the .ipynb notebooks, the comparision table of different projects, the data used the outputs from both the methods and evaluation of the Qwen model for the task of document text extraction.

The results have been evaluated on Qwen model.

1. The **field-level** accuracy for **fixed layout** documents is **66.701%** and for **variable layout** documents is **63.5%**.
2. The **character error rate** for **fixed layout** documents is **36.24%** and for **variable layout** documents is **10.82%**.
3. The **latency per page** for **fixed layout** documents is **26 seconds** and for **variable layout** documents is **99.3 seconds**.
4. Assuming the rate to be 9 rupees kwh and the program running on bank's own GPU the **cost per 1000 pages** for **fixed layout** documents is **64.8 rupees** whereas for **variable layout** documents is **247 rupees**.
